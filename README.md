# 🚨 121.5 — Система аварийных ситуаций (MAYDAY)

**Реализм начинается там, где заканчивается обыденность.**

121.5 — это внутренняя система Домодедовского авиапредприятия, имитирующая реальную аварийную частоту. Она нужна не для драмы, а для **дисциплины, обучения и разбора полётов**: каждый отказ фиксируется, каждый вызов отрабатывается, каждый репорт становится материалом для роста пилота и всей ВАК.

Система состоит из **двух каналов**, каждый со своей функцией: текстовый — для документальных репортов, голосовой — для работы в реальном времени.

---

## 📝 Текстовый канал — Репорты инцидентов

После каждой нештатной ситуации пилот **обязан** оформить официальный репорт в текстовом канале 121.5.

> ⚠️ Важно: репорт подаётся **после посадки**, а не в воздухе. В воздухе — только голосовой MAYDAY-вызов. Текст — это уже документ.

### Структура репорта

Репорт пишется по единому шаблону — чтобы диспетчеры, инструкторы и разработчики могли быстро разобрать инцидент:

- **Шапка** — тип инцидента / аэропорт / тип ВС / бортовой номер
- **Время (UTC)** и краткое описание происшествия
- **Позиция ВС** на момент отказа — маршрут, этап полёта, удаление от полосы
- **Каскадные отказы** — перечень систем, которые «посыпались» вслед за первичным отказом
- **Действия КВС** — какие чек-листы выполнены, как восстановлено питание, как велось управление
- **Итог** — посадка, вертикальная скорость касания, состояние пассажиров
- **Статус** — расследование, необходимые работы по ВС

### Пример репорта (эталон)

## 🎙️ Голосовой канал 121.500 — Онлайн-мониторинг

Голосовой канал 121.500 — это «живая» аварийная частота ВАК. Здесь пилоты держат связь в течение всего полёта, а дежурный диспетчер следит за обстановкой и готов прийти на помощь в любую секунду.

> 🎧 Диспетчерская служба 121.5 находится в стадии запуска — дежурства появятся чуть позже. Сейчас канал работает в тестовом режиме.

### Как это работает

1. **Пилот выходит в рейс** и заходит в голосовой канал 121.500 — как на реальной аварийной частоте, держит связь весь полёт.
2. **При отказе** — короткий MAYDAY-вызов по установленной форме:
MAYDAY MAYDAY MAYDAY, [позывной], [характер отказа]

Пример из практики:
MAYDAY MAYDAY MAYDAY, RA-73800, AC TRANSFER BUS 1 FAIL


3. **Диспетчер 121.5** принимает вызов, уточняет обстановку, подсказывает порядок действий по чек-листу, при необходимости координирует с УВД и другими бортами.
4. **После посадки** пилот оформляет репорт в текстовом канале (см. выше).

### Роль диспетчера 121.5

- Мониторит голосовой канал и текущие онлайн-рейсы ВАК
- Принимает MAYDAY и уточняет детали: тип отказа, позиция, высота, запас топлива, намерения КВС
- Выдаёт **информационную поддержку** — не командует, а помогает пилоту вспомнить правильный порядок действий
- Фиксирует инцидент и после посадки сверяет голосовой вызов с текстовым репортом

### Пример обмена (голосом)
ПИЛОТ: MAYDAY MAYDAY MAYDAY, RA-73800, AC TRANSFER BUS 1 FAIL.
ДИСП: RA-73800, 121.5, понял MAYDAY. Доложите позицию, высоту, топливо.
ПИЛОТ: Финальный, 10 миль, 2500 футов, топливо 3.2 тонны.
ДИСП: RA-73800, принял. Рекомендую: запуск APU вручную, восстановление
сети через APU GEN 1, управление — вручную. Сообщите о стабилизации.
ПИЛОТ: Понял, выполняю. Сеть восстановлена через APU GEN 1, заход визуальный.
ДИСП: RA-73800, принял. Работайте, я на связи. После посадки — репорт в канал.
